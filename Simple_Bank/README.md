A menu-driven banking application written in Python that allows users to manage bank accounts through the command line.
Features:
- Account login using username and PIN
- Account creation
- Balance checking
- Deposits
- Withdrawals
- Money transfers between accounts
- Input validation for transactions and account creation
Concepts used:
- Functions
- Dictionaries
- Nested dictionaries
- Loops
- Conditional statements
- User input handling
This project was built as practice for learning Python functions and data structures while modeling a simplified banking system.
